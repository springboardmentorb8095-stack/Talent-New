# Talent Link

## Description
Talent Link is a freelance platform where clients can post projects and freelancers can bid on them. This project includes a Django backend and a React frontend.

## Features
- Client dashboard: post and manage projects
- Freelancer dashboard: view project feed, bid, and see accepted projects
- Proposal system: freelancers submit proposals, clients accept/reject them
- JWT authentication for secure login

## Tech Stack
- Backend: Django, Django REST Framework, SQLite
- Frontend: React.js, Axios
- Authentication: JWT (SimpleJWT)
- Other: React Toastify for notifications
